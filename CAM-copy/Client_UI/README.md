# Solano High School Teacher Portal Prototype

A responsive HTML, CSS, JavaScript, and Bootstrap 5 prototype for the teacher-side Certificate of Appearance workflow.

## Run the prototype

Open `index.html` directly in a browser, or serve the folder with XAMPP at `http://localhost/Research/`. Bootstrap and its icons are loaded from a CDN.

## Demo sign-in

The app demonstrates login validation, dashboard summaries, request submission and drafts, request search and status filtering, appearance recording for approved activities, certificate previews and printing, profile updates, and feedback.

## Prototype limitations

This is a front-end-only demonstration. Authentication, role checks, approvals, appearance records, certificates, and feedback are simulated and stored in the current browser's `localStorage`. They are not sent to Solano High School and do not provide production security or official records. A real deployment requires a secured backend, database, server-side authorization, and school-approved appearance and certificate procedures.
